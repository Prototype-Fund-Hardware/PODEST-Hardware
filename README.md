# PODEST Hardware

This repository contains the hardware developments of the PODEST project.

PODEST ("Potentiale von Open Source Hardware für dezentrale Energieversorgung") is a research project investigating how open-source hardware can support decentralized renewable energy systems and increase participation in the energy transition. The project is carried out by TU Berlin, BTU Cottbus-Senftenberg, and the Open Knowledge Foundation Germany (OKF DE).

The goal is to develop and document a modular, open-source energy system that can be adapted, repaired, improved, and reproduced by different stakeholders, including researchers, companies, community initiatives, and technically interested users.

## Repository Structure

The repository is organized into the main hardware components of the system:

## System Overview

The individual components are designed to form a complete decentralized renewable energy system.

The system combines renewable energy generation, battery storage, power conversion, and system control in a modular architecture. A key objective is to enable flexible integration of different hardware components and technologies while maintaining a fully documented open-source design.

## Project Objectives

The project focuses on:

- Open-source hardware for decentralized energy systems
- Modular and repairable system architectures
- Integration of renewable energy sources
- Open documentation and knowledge transfer
- Long-term maintainability and reuse of hardware designs
- Community-driven development and collaboration
